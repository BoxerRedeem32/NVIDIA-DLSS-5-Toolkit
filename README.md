## 🎯 What This Tool Does

NeuralRendering Toolkit is a Windows application built for RTX 50 series owners who want to use DLSS 5 neural rendering in their games.
It handles detection, version checks, driver verification and safe file replacement — all in one place.
No guesswork, no manual DLL swapping.

## ⚡ Capabilities

- 🧠 DLSS 5 neural rendering activation
- 🔍 Driver and GPU compatibility check
- 💾 Rollback system with automatic backups
- 🎮 Game library scan (Steam, GOG, Epic, Battle.net, Ubisoft, Xbox)
- 📁 Custom install path support
- 🎛️ Adjustable enhancement strength
- 🌙 Dark and light interface
- 📴 Offline mode after initial setup

## 💻 Requirements

- Windows 10 / 11 (64-bit)
- NVIDIA GeForce RTX 50 series GPU
- Game Ready driver (September 2026 or newer)
- .NET 9.0 Runtime
